# Le Cercle

The static build of [cercle.corentinsueur.com](https://cercle.corentinsueur.com/), served by GitHub Pages. Every file here is generated; changes made in this repository are overwritten at the next publish.

Le Cercle maps who staffed French ministers' offices, the Élysée and Matignon since 1990, and links them to their later careers, to state boards, and to the companies, lobbies and public contracts around them, from public records.

- **Sources, licences, corrections and objections, personal data and legal notice:** [the About page](https://cercle.corentinsueur.com/about.html) ([English](https://cercle.corentinsueur.com/en/about.html)).
- **Data:** the JSON files under `data/` are what the site reads. Each comes from the sources listed on the About page, under their own licences, and the personal data it holds stays under the GDPR whoever reuses it. To ask for a correction or to object, use the contact on the About page.
